Go is designed to make efficient, reliable software easy to write, and concurrency support is one of its key features. In this post I&apos;ll show how to use Go&apos;s lightweight threads (goroutines) and channels to build concurrent applications.

## What is concurrency?

Concurrency is the ability of a program to make progress on multiple tasks in overlapping time. The tasks can run in parallel on multiple cores, but they don&apos;t have to. A program can get it from multiple threads, processes, or lightweight threads (goroutines in Go). Concurrency helps you build efficient, responsive applications, especially for I/O work such as reading from a file or making a network request.

## Goroutines

Goroutines are lightweight threads managed by the Go runtime. They are like threads in other languages, but more efficient and easier to work with. You create a goroutine with the <Snippet>go</Snippet> keyword, and the runtime schedules it on available CPU cores.

* **The 'go' keyword.** <Snippet>go</Snippet> launches a function as a goroutine, so it runs concurrently.



 Here is a simple goroutine:

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    go func() {
        fmt.Println("Hello from a goroutine!")
    }()

    time.Sleep(1 * time.Second)
}
```

The goroutine prints "Hello from a goroutine!" to the console. The <Snippet>time.Sleep</Snippet> call waits for it to finish before the program exits.
## Channels

Channels let goroutines pass data to each other safely and efficiently. They are a key part of Go&apos;s concurrency model.

* **Channel basics.** You create a channel with <Snippet>make(chan type)</Snippet>. Each channel is typed by the kind of data it carries.
    * **Sending:**  <Snippet>ch &larr; value</Snippet>
    * **Receiving:** <Snippet>value := &larr; ch</Snippet> (Receiving blocks until data is available)

Here is a simple channel:

```go

package main

import "fmt"

func main() {
    ch := make(chan int)

    go func() {
        ch <- 42
    }()

    value := <-ch
    fmt.Println(value)
}
```

This example creates a channel of type <Snippet>int</Snippet> with <Snippet>make</Snippet>. A goroutine sends <Snippet>42</Snippet> to the channel with the <Snippet> &larr; </Snippet> operator, and main reads it back with <Snippet> &larr; </Snippet> and prints it.

## Conclusion

This post covered creating and managing goroutines, and using channels to communicate between them.

Go&apos;s concurrency model helps you build efficient, responsive applications, especially ones that do a lot of I/O.
