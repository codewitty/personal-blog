## Concurrency fundamentals

Concurrency is the ability of a program to deal with multiple tasks in overlapping time. The tasks don&apos;t have to execute at the same instant. That&apos;s parallelism. Concurrency means the program makes progress on one task while it waits on another.

## Threads: the traditional approach

Languages like Python and Java traditionally rely on operating system threads for concurrency. Each thread has its own execution flow and its own stack. Threads are powerful, but they come with two problems:

* **Overhead.** Threads use a lot of memory, and context switching between them can be slow.
* **Synchronization complexity.** Shared data needs synchronization (locks, etc.) to prevent race conditions.

## Go&apos;s approach: goroutines and channels

Go takes a different approach:

* **Goroutines.** Lightweight "threads" managed by the Go runtime. They start with tiny stacks that grow as needed, and the runtime schedules them across available threads.
* **Channels.** Typed pipes that goroutines use to communicate. Sending and receiving on a channel synchronizes the goroutines implicitly.

## Example: simulating network requests

Here&apos;s a simplified example of each approach:

**Python (threading):**

```python
import threading
import time

def fetch_data(url):
    # ... simulate network call ...
    time.sleep(1) 
    print(f"Fetched data from: {url}")

threads = []
for url in ['https://site1', 'https://site2']: 
    t = threading.Thread(target=fetch_data, args=(url,))
    threads.append(t)
    t.start()

for t in threads:
    t.join()
```

**Go (channels):**

Goroutines fetch from multiple websites concurrently, and a channel collects and synchronizes the results.

```go
package main

import (
    "fmt"
    "net/http"
    "time"
)

func fetch_data(url string, ch chan string) {
    // Simulate an actual network request
    resp, err := http.Get(url) 
    if err != nil {
        ch <- fmt.Sprintf("Error fetching from %s: %v", url, err)
        return
    }

    // Simulate some processing time
    time.Sleep(2 * time.Second) 

    ch <- fmt.Sprintf("Fetched %d bytes from: %s", resp.ContentLength, url) 
}

func main() {
    ch := make(chan string)
    for _, url := range []string{"[https://www.google.com](https://www.google.com)", "[https://www.example.com](https://www.example.com)"} {
        go fetch_data(url, ch) 
    }

    for i := 0; i < 2; i++ {
        fmt.Println(<-ch) 
    }
}
```
